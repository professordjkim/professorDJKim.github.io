Team

The SABR Lab (Software Analysis, Automation, Benchmarking, and Re-engineering) at DePaul University works on LLM-driven techniques for software reliability — AI-assisted code understanding, runtime observability, fault localization, and developer workflows.

Principal Investigator

  • Dong Jae (DJae) Kim — Assistant Professor, Jarvis College of Computing and Digital Media, DePaul University Ph.D. from Concordia University (2024), advised by Tse-Hsun (Peter) Chen. Research on software debugging, testing, maintainability, program analysis, mining software repositories, and AI-driven software engineering. Email/ CV/ Google Scholar/ GitHub/ LinkedIn

Ph.D. Students

  • Fairuz Bilquis Khan — Ph.D. student (since Sep 2025) LLM-based code navigation, execution analysis, and agent context management.

Student Research Projects

Undergraduate and graduate students contribute to lab projects, including work through DePaul's Undergraduate Research Assistant Program (URAP):

  • Firefox crash-telemetry fault-localization benchmark — URAP, 2026 Building an enterprise-scale fault-localization benchmark from Mozilla Firefox crash telemetry, in collaboration with Mozilla.
  • A Framework for Accessible Web Interfaces — Motorola Solutions Foundation, 2025–2026 Tooling for accessible web interfaces and adaptive user onboarding, supported by the Motorola Solutions Foundation.
  • Automated penetration testing with multi-agent systems — URAP, 2024 Multi-agent LLM systems for automated security testing of web applications.
